Confidentialité — Notif Cashback

Dernière mise à jour : 16 septembre 2026. Éditeur : Demiwind.

Ce que fait l’extension

Notif Cashback compare le nom d’hôte de la page visitée à une liste d’enseignes The Corner (BoursoBank). Si ça correspond, elle affiche un rappel dans la popup et, si tu l’as activé, une notification.

Données traitées

  • Nom d’hôte de l’onglet courant (pour le matching), uniquement dans le navigateur.
  • Préférences (notifications, enseignes masquées) dans le stockage de l’extension.
  • Catalogue d’offres public, téléchargé pour mettre à jour la liste des enseignes.

L’extension ne lit pas le contenu des pages, ne crée pas de compte, et n’envoie pas ton historique de navigation à un serveur d’analytics.

Ce qui n’est pas collecté

Pas d’identifiants bancaires, pas de paiement, pas de liste d’achats. Le parrainage ouvre le site officiel BoursoBank. Ko-fi est un don volontaire, hors Bourso.

Partage

Aucune revente de données. Le catalogue d’enseignes est un fichier public, sans t’identifier.
